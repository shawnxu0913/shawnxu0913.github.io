# shawnxu0913.github.io

Personal blog, built by GitHub Pages (Jekyll, minima theme).

- Posts: `_posts/YYYY-MM-DD-slug.md`. Add `math: true` to the front matter to load MathJax; write math as `$$...$$` (inline or as its own block).
- Figures: `assets/img/`. The Milestone 1 figures are generated by `python _tools/figures.py`.
- Local preview (optional, needs Ruby): `bundle install && bundle exec jekyll serve`.
